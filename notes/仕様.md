# 仕様

最終更新日: 2026-11-19

## 1. 概要
- プロジェクト名: testClaudeCoding
- 目的: インタラクション作品の展示を告知する PR 用ホームページを作成する。
- 言語: Python 3.11 以上（`tomllib` を使用）。テンプレートエンジンに Jinja2 を使用。
- 方式: 静的サイトジェネレーター。`site.toml` の内容を Jinja2 テンプレートに流し込み、`dist/` に HTML を出力する。

## 2. 構成
| パス | 内容 |
| --- | --- |
| `build.py` | サイト生成スクリプト（`--serve` でローカルプレビュー） |
| `site.toml` | 掲載内容（作品・展示・作家・お知らせ・FAQ・連絡先） |
| `templates/` | Jinja2 テンプレート（`base.html`, `index.html`） |
| `static/css/style.css` | スタイル |
| `static/js/main.js` | ヒーロー部分のインタラクティブ演出 |
| `tests/` | pytest によるテスト |
| `dist/` | 生成物（Git 管理外） |
| `CLAUDE.md` | Claude Code の使用規約 |
| `notes/` | 仕様・進捗 |

## 3. 機能仕様

### 3.1 サイト生成（build.py）
- 入力: `site.toml`（`--content` で変更可）
- 出力: `dist/index.html` と `dist/static/`（`--out` で変更可）。出力先は毎回作り直す。
- お知らせ（news）は日付の新しい順に並べ替える。
- テンプレートは自動エスケープ有効。未定義の値を参照した場合はエラーにする（StrictUndefined）。
- `--serve` 指定時は生成後にローカル HTTP サーバーを起動する（`--port` 既定 8000）。

### 3.2 ページ構成（1ページ構成）
1. ヘッダー: タイトル、各セクションへのナビゲーション
2. ヒーロー: 会期・タイトル・サブタイトル＋インタラクティブな光の粒子
3. News: お知らせ一覧
4. About: 作品紹介文と特徴（3項目）
5. Information: 会期・開館時間・休館日・入場料・会場
6. Artist: 作家プロフィール
7. FAQ: 開閉式の Q&A
8. Access: 会場住所・交通案内（`map_url` 設定時は地図ボタン表示）
9. フッター: 問い合わせ先・SNS リンク

### 3.3 インタラクティブ演出（main.js）
- 光の粒子がポインター（マウス・指）に引き寄せられる。
- クリック/タップで波紋が広がり、粒子を押し出す。
- 近い粒子同士を線で結ぶ。
- `prefers-reduced-motion` 設定時はアニメーションを停止する。

## 4. 非機能要件
- レスポンシブ対応（640px 以下でスマートフォン向けレイアウト）。
- 外部 CDN に依存しない（静的ファイルのみで動作）。
- OGP の基本タグ（title / description）を出力する。

## 5. 未確定事項
- `site.toml` の作品名・会期・会場・作家名などはすべて仮の内容。実際の情報に差し替えが必要。
- 作品写真・映像、OGP 画像、地図 URL は未設定。
