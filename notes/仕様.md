# 仕様

最終更新日: 2026-11-19

## 1. 概要
- プロジェクト名: testClaudeCoding
- 目的: 展示作品『My Cover』（池田うさぎ／武蔵野美術大学 デザイン情報学科3年 大石ゼミ）の紹介ページを作成する。
  - 展示: デザイン情報学科3年ゼミ展「滲む、響く。」 2026年12月3日（木）〜5日（土）、鷹の台キャンパス 9号館地下
  - 来場者が会場の QR コードからスマホで開くことが多いため、**スマホ表示を最優先**とする。
- 元資料: 作品紹介ページ制作の依頼書（`my-cover_hp_prompt.md`、ユーザー提供）
- 言語: Python 3.11 以上（`tomllib` を使用）。テンプレートエンジンに Jinja2 を使用。
- 方式: 静的サイトジェネレーター。`site.toml` の内容を Jinja2 テンプレートに流し込み、`dist/` に HTML を出力する。
- 原則: 依頼書に書かれていない事実（アーティスト名・楽曲名・人数・成果など）は作らず `【要記入】` とする。

## 2. 構成
| パス | 内容 |
| --- | --- |
| `build.py` | サイト生成スクリプト（`--serve` でローカルプレビュー） |
| `site.toml` | 掲載内容（文言・画像パス・代替テキスト） |
| `templates/base.html` | HTML の共通部分（meta / OGP） |
| `templates/index.html` | ページ本体 |
| `templates/_macros.html` | 正方形画像枠・セクション見出しのマクロ |
| `static/css/style.css` | スタイル（スマホ優先、720px 以上で PC レイアウト） |
| `static/js/main.js` | ファーストビューの「にじみ・波紋」演出 |
| `static/images/` | 差し替え用画像の置き場所 |
| `tests/` | pytest によるテスト |
| `dist/` | 生成物（Git 管理外） |

## 3. 機能仕様

### 3.1 サイト生成（build.py）
- 入力: `site.toml`（`--content` で変更可）／出力: `dist/`（`--out` で変更可、毎回作り直す）
- お知らせ（news）は日付の新しい順に並べ替える。
- 自動エスケープ有効。未定義の値を参照した場合はエラー（StrictUndefined）。
- `--serve` で生成後にローカル HTTP サーバーを起動（`--port` 既定 8000）。

### 3.2 ページ構成（1ページのスクロール型）
見出しは曲目リスト風に番号＋英語＋日本語で表記する。

| 番号 | セクション | 内容 |
| --- | --- | --- |
| — | ファーストビュー | 正方形のジャケット枠に展示テーマと「My Cover」、サブタイトル、会期・会場 |
| — | News | お知らせ（内容は【要記入】） |
| 01 | About | 作品概要、架空アーティスト名・楽曲名（【要記入】）、タイトルの2つの意味 |
| — | Covers | 生成ジャケットの作例（正方形の画像枠 ×4） |
| 02 | Experience | 体験の流れ 6 ステップ（聴く／言葉にする／生まれる／持ち帰る／並ぶ／戻ってくる） |
| 03 | Research | 研究の問いと、来場者向けの注意書き（**掲載必須**） |
| 04 | System | 生成の流れ図と技術の説明 |
| 05 | Exhibition | 展示名・テーマ・会期・時間・会場・形式、会場の構成、展示風景の画像枠 ×3 |
| — | FAQ | よくある質問（内容は【要記入】） |
| 06 | Credit | 制作者・所属 |
| — | フッター | 問い合わせ先・SNS（内容は【要記入】） |

- 研究として記録する項目（入力語・生成数/保存数・カード持ち帰り・再訪・アンケート）は掲載しない（注意書きのみ掲載）。

### 3.3 画像の扱い
- 画像はすべて正方形の枠で表示する。`site.toml` の `image` が空なら「【要記入】」のプレースホルダー枠を表示する。
- 画像には `alt`（代替テキスト）を必ず設定する。
- メインビジュアル（`hero.image`）が未設定の間は、ファーストビューに canvas の演出を表示する。設定すると画像に切り替わる。

### 3.4 デザイン
- 暗いレコードスリーブ／ライナーノーツ風（黒地・生成り色の文字、余白多め）。
- 正方形（ジャケット）のモチーフ：ファーストビュー、画像枠、ステップ番号。
- 「滲む、響く。」：ジャケット枠内で色の玉がゆっくり漂いにじむ。タップ／クリックで波紋が広がる。
- `prefers-reduced-motion` 設定時はアニメーションを止める。

## 4. 非機能要件
- スマホ優先のレスポンシブ（720px 以上で 2 カラム等の PC レイアウト）。
- アクセシビリティ: 本文のコントラスト比 約16:1、補足テキスト 約9:1。本文 16px 以上。スキップリンク、代替テキスト、フォーカス表示。
- 外部 CDN に依存しない。
